Step 1

Meet the two PLCs

P1 is the raw-water intake of the plant: a tank that fills from the river through a fill valve. In the SPHERE ICS cluster two Rockwell ControlLogix PLCs run it. PLC 1 is the controller. PLC 2 plays the plant: it sends PLC 1 a tank-level reading and receives the valve command back.

The control rule is simple. When an operator presses Start and the tank reads between 300 and 500 mm, PLC 1 opens the fill valve. Above 500 mm it closes the valve, so the tank never overflows.

Expected: you can say which PLC makes the decision (PLC 1) and which wires carry the level reading and the valve command.

Step 2

Play the recording

On October 10, 2026 we ran one short test on the two PLCs. A script set the level reading to 315 mm and pressed Start for about half a second. The whole test lasts two seconds, so playback runs at one-third speed.

  1. Press Play recording and watch all three panels.
  2. Press Previous and Next to step one sample at a time. Each panel shows the sample number and when its next change comes.
  3. Use the phase buttons to jump to the moment Start is pressed.

Step 4

See what an attacker could do

PLC 1 trusts its level reading. In the October 10 test a script changed that reading over the network to start the fill. An attacker with the same network access could use it to keep the fill going past the 500 mm limit. Click through the four stages. This is an illustration built from the test setup; the recording itself contains only the scripted test.

About this recording

Recorded on 2026-10-10 MDT on the SPHERE Rockwell pair. The test held the level at 315 mm for about 0.9 s and Start for about 0.55 s, then put both back. The simulated tank was paused, so the level changed only when the script set it. The values come from the two PLCs’ memory; an independent level sensor was not part of this test. The source capture has SHA-256 dbce0fdc0032a9afa55537d1f845db0c17b15f3653114295473348e76f173e47, with 8 baseline, 7 level-raised, 11 Start, and 16 back-to-normal samples.

Names on this page and their PLC tags: level reading P1.RW_Tank_tnk_lvl; fill-valve command P1.RW_Tank_PR_Valve; PLC 1 output slot 5, point 0 Local:5:O.Data.0; PLC 2 input slot 5, point 0 Local:5:I.Data.0.
